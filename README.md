
# SOC Incident Response Portfolio

## About This Project
This repository demonstrates my understanding of cybersecurity incident response, threat detection, evidence analysis, and security remediation.

The project includes simulated security incidents investigated from the perspective of a Tier 1 Security Operations Center (SOC) analyst.

All incident details and evidence are fictional and were created for educational purposes.

## Objectives
- Identify and analyze suspicious security activity
- Document incidents using the five W's
- Create evidence logs and investigation timelines
- Map observed behavior to the MITRE ATT&CK framework
- Recommend containment, eradication, and recovery measures
- Communicate technical findings clearly

## Incident Investigations

### Case 001: Phishing Email with Suspicious Attachment
A simulated HR employee receives a malicious job application email. The investigation evaluates phishing indicators, suspicious attachment activity, possible endpoint compromise, and appropriate response procedures.
